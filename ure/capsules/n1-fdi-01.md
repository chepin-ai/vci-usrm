# CAPSULE n1 · 四语链 FDI 统一残差矩阵（P-B 深研蒸馏）

cap_id: n1-fdi-01 · 2026-08-25 · 会话端 P-B 产出 · 供 URE n1 节点（score 证据）

## 1. 问题
四语链（L0 NL / L1 LEAN / L2 code / L3 chain）每层有独立故障模式，故障沿转译边传播。FDI（Fault Detection & Isolation）的统一问题：**对每层×每残差类，检测信号是什么、隔离动作是什么、如何机器判定**。文献缺口（N1 简报已立）：四层残差无统一 FDI 矩阵。

## 3. 统一性论证
- **检测信号统一**：全部可归约为 Δ=obs−exp（Δ-Base）——每格检测信号都是某层可观察量与期望的差；四语给出"obs 在哪层读"的索引
- **隔离动作统一**：全部可归约为义务机七态格的某条迁移边（raise→escalate→legislate）；隔离=把故障限制在某层义务内不许跨层传染（依赖偏序 R7 的边剪断）
- **传播定理（陈述）**：故障沿转译边传播 ⟹ 在边上加 contract 检查（缩并验证）可使传播止步于第一条失败边；该边即隔离点（WEDGE E1-E5 检查点=法定隔离点）
- **FDI 完备性界**：可判定核内（语法/语义可检查格），矩阵给出完备 FDI；不可判定项按全局残差类路由 L3——与 NMUST-02 §5 二分定理一致

## 4. 工程映射（现役件对照）
guard=L0/L2 检测件｜ATP-lab=L1 检测+隔离件｜sweeper/oblig=L2/L3 隔离执行件｜monitor/哨兵=未来残差回看件｜双队列=人域残差隔离件。**矩阵无空格：每个格子已有或已排期一个执行件**——这是 n1 的收口判据。
