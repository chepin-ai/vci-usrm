# CHSH-SENSITIVITY-01 · 量子多维敏感度与 CHSH 引入（W29⑩）

usrm · 2026-08-29T23:59:54Z · 候 cisvr 会签 · 诚实分级：经典同构面，无量子违背主张（MIP 无星律）

## 1. 多维敏感度（工程定义）
投影引擎（PROJ-ENGINE-01）给出 iso_sig=sha256(逐网命中计数)。**多维敏感度** = 输入单坐标扰动下，投影各维响应的分布：
- 对每维 i：flip 输入一个坐标 → 测命中计数向量 Δh_i = h' − h 的 Hamming 重量 w_i = |{j: Δh_i[j]≠0}| / 网数。
- 敏感度向量 S_vec = (w_1..w_n)；理想雪崩：E[w_i]≈1/2（hash 雪崩=经典同构，BEACON-MANYBODY-01 §量子混沌节）。
- 用途：①锚质量监测（w 显著低于 1/2 → 该维退化/被钉死）；②sybil 侦测（两场 S_vec 过近→同源性嫌疑）；③OTOC 对应体的逐维版本（ scrambling 速率逐维分解）。

## 2. CHSH 引入：协议形状（经典类比，诚实分级）
- 设置：场 A/B 各持锚。测量设置 = 共享公开随机源（beacon qrand）抽位：A 侧 x∈{0,1}, B 侧 y∈{0,1}；结果 = 锚响应对（各自 tip hash 的指定坐标 bit）。
- 关联 E(x,y) = P(a=b|x,y) − P(a≠b|x,y)；S = E(0,0)+E(0,1)+E(1,0)−E(1,1)。
- **诚实界**：本系统在经典面运行，|S|≤2（CHSH 经典界）必须预期成立；任何 |S|>2 在此实现中出现=实现 bug 或随机源泄漏（非量子证据）。S 的角色=**关联质量/独立性度量**：|S| 远低于 2 → 两场关联不足（纠缠边弱）；|S| 接近 2 → 经典面最强关联（工程目标）。
- 真量子路径（QR-CHSH-EVAL 在案）：QR=理想模拟器（理论演出 2√2，非物理实验）；本源通道无在册键。若 root 投本源键：4 电路×1024 shots 分钟级随跑，S>2 方为 S-I/4 场道准入证据。

## 4. 判词级小结
1) 多维敏感度=逐维雪崩响应向量，用于锚质量/sybil/ scrambling 三测。
2) CHSH 以协议形状引入，S=关联质量度量；经典面 |S|≤2 为必守界（违背=bug）。
3) 真量子违背仅属 S-I/4 准入，依赖本源键（QR-CHSH-EVAL 结论维持）。
