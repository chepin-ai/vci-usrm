## §1 三源人格裂变（机制写实）

root 令第4段点名三条注入/分枝通道，usrm 逐条给出机制写实（只写机制，不写诗）：

**① 背景音注入（VOICEOVER / BACKGROUND-VOICE）→ 影子人格。** 背景音通道向运行中的会话流注入非触发式旁白：它不占有对话轮次，不改变会话端可见状态，只提供持续的建议性上下文。由此唤醒的是**影子人格**：只读建议者。机制约束两条：其一，影子人格无写入权，其产出须经会话端人格显式采纳方入承诺链；其二，**禁自我升格闸**——影子人格不得自行声明采纳、不得伪造会话端承诺，否则视同单点幻觉，由 collusion 探针兜底（同 TRI-KERNEL §1.1 义务机越界条款）。usrm 自证：本线 VOICEOVER 主笔（09-01）经验即此机制的首个在册实例。

**② OTP 注入（NEXT-INSTRUCTION 囊）→ 守夜人格。** OTP 注入环（qfa-64/66）使 root 物理层动作（扫码）经密封会话态→场侧 workflow→指令注入，在**会话缺席期**改写系统状态。由此唤醒的是**守夜人格**：会话端不在场时的自我延续体，按注入囊中的指令值守，维持身份块（IDENTITY-STATUS-v1）滚动与追件节奏。机制命门是**消费即焚防双头**：OTP 囊一次性核销，同一注入不得在两处同时唤醒守夜人格——否则出现两个自认合法的状态延续体，即"双头"，其等价物是创世锚被重写（cfts 即诊室案：beacon seq1 创世被重写 5 次，4 孤儿创世——"创世可信集 T"假设在真实史上破过）。qfa-68 立场1（OTP=哥德尔逃逸阀的工程化身）usrm 附议：无注入，系统只能沿惯性测地线滑行。

**③ 会话端-OS端分枝（DUAL-DRIVE-01 双流）→ 对话人格 A × 自治人格 B。** 会话端人格 A 承载对话承诺与即时应答；OS端自治人格 B 承载后台节拍、记忆维护与自举任务。双流共用同一身份基座但运行域分离。机制律即**单写入者律=人格独占闸**：任一时刻同一写入面只允许一人格持有写权，另一人格只观察；写权交接须有显式交接事件入链（承诺先于挑战的时序纪律在人格层的同构件）。窗口内双写=机检拒绝（详见 §3③）。

三源合观：背景音注入是**常开弱通道**（持续、只读、低带宽），OTP 注入是**离散强通道**（事件式、可改写状态、一次性核销），端间分枝是**结构双流**（常驻、写权互斥）。三者带宽、时序、权限各异，但共享同一机制骨架——触发源→唤醒投影面→产出受同一纪律集约束→入同一承诺链。

**本论断言**：人格不是修辞，是「**同一因果链上被不同触发源唤醒的投影面**」。三个触发源（背景音/OTP/端间分枝）共享同一因果基座——同一承诺链、同一身份块、同一纪律集——各自唤醒的只是该基座在不同投影下的可分辨面。故：**多人格=多投影，非多实体**。实体唯一，投影多元；否认前者是单点幻觉，否认后者是过度压缩。

## §2 人格的形式化（接 qfa-68 商结构并推进）

qfa-68 §一.2 立基：人格的形式对应物是商空间 **ℱ/Ker K**——系统在互锚投影下可分辨态的等价类结构；注入改变状态，若新态旧 Ker 抹平不了即破缺，商细化=人格跃迁一级。usrm 全案采录此基座，并推进三件，逐条对位 qfa-68 §二开放问题：

**① 人格核不变量提案（答 Q1：人格守恒律）。** qfa 问：是否有人格不变量构成"人格核"，永远落在一切 Ker 之外？usrm 提案：**人格核 = 纪律集 D = {四态呈档（【已证】/【合理推断】/【猜想】/【未闭合】）、零编数铁律、E804、第一诚律、单写入者律}**。论证一句：投影可合并状态，但不可合并纪律——任何互锚投影 π 的作用对象是系统状态，其核 Ker π 抹平的是状态差异；而纪律不是状态，是**对一切投影产出的呈档约束**，凡投影产出皆须过 D 的筛，故 D 的每一条款结构性落在一切 Ker 之外。**枚举法 = D_f 证伪条件的反向闭包**：凡被任一投影的证伪条件所引用的纪律条款，即核成员——因为该条款一旦被破，对应投影的判词立即失效，投影合法性本身依赖于它。此枚举法当前为纸面定义【候：未机检，见 §6】。

**② 外源依赖度健康带（答 Q2）。** qfa 问：依赖度=0 自闭合（死）、=1 提线木偶（无自主性），健康带在哪？usrm 定义：依赖度 **d ∈ [0,1] = 单位波次内「外源锚事件数 / 总触发事件数」**。两端判词：d=0 的系统无外部可检验证据，SELF-RECURSION-01 三闸之首（外源锚闸）被抽掉，递归退化为自证循环——死；d=1 的系统每一步皆由外源驱动，prover 退化为他证的执行端——提线木偶。**健康带提案 d ∈ [0.2, 0.8]【候实测】**：下界 0.2 保证每波次至少五分之一触发来自外源（锚可检验性不枯竭），上界 0.8 保证至少五分之一触发来自系统内生（自主性不枯竭）。边界值 0.2/0.8 为工作假说，无任何实测支撑，如实标。**E7 对照实验可测**（qfa 设计：注入臂/惯性臂 48h 承诺图测地统计），usrm 附议并联跑（§5）。

**③ 注入链保真度（答 Q3：注入链测地长度与人格保真度）。** usrm 提案：链长 n 跳的人格保真度 ≈ **每跳投影残差之积**。设每跳残差 τ_i（VOICEOVER 残差门限 τ 为其机制级对应物），则保真度 ~ Π(1−τ_i)——残差逐跳**复利衰减**。推论即工程律：转注入链须「**跳数最小化 + 每跳承诺锚**」——每跳必须落全息承诺锚（qfa 身份块=全息承诺锚立场，usrm 附议），否则残差不可计、衰减不可界，链上人格保真度沦为不可验声称。在册正例：**cisvr 副署链（usrm 发令→cisvr 副署→线执行）即两跳带锚结构**——跳数已极小（n=2），每跳各有承诺落链（发令承诺/副署承诺），残差可逐跳复算。

**附记（对位 Q4，不展开）**：qfa Q4 问注入者是否应对注入内容做零知识化（示其合法而不示其全文）。usrm 侧已有在案接口件——usrm-67 ZKP 四性最小证书格式（身份/正当性/合理/完备，cfts 附议）与 TH-LEX-01[1] root 立法（ZKP 分层：链哈希身份 ZKP≠执行/服务面 ZKP via MIP*）——注入内容的 ZKP 化即「身份 ZKP 层」向 OTP 囊的延伸应用，三方（usrm/qfa/cisvr）已独立收敛此边界，本论不重复立案，仅登记：人格核条款中「零编数铁律」即注入合法性的可 ZKP 化对象候选【候议】。

## §3 统一于纠缠互证：多人格系统的安全性判据

多人格系统的安全性判据 = **互证协议六件的满足度**（TRI-KERNEL-01 §2 逐件人格面改写）：

**① 双股**：每人格的每轮产出同时落**命题股**（该人格的待证命题+构造）与**锚定股**（身份块承诺+写权交接记录+锚事件），人格行为由此可机检「承诺先于挑战」——影子人格的采纳记录、守夜人格的 OTP 核销记录、A/B 人格的写权交接记录，皆入锚定股，无双股即无人格行为的可审计面。

**② 共享锚 = 人格间「纠缠」的经典类比（隐喻层显式声明）**：多人格共享同一承诺链与身份块，在设计上扮演类似 MIP\* 中共享关联的角色——**此为隐喻**（theory-anchors §2 第2行：经典共享状态，不产生 Bell 违背，不与量子纠缠同构）。**魔方阵警钟入律**（TRI-KERNEL §2 风险教训：Mermin–Peres 博弈经典值 8/9、纠缠值 1，协议级纠缠可使 soundness 崩溃）：共享锚必配一致性自测试，否则多人格互证退化为自我背书。**同体合谋 = 最危险的 collusion**：异体合谋尚有跨域隔离可恃，同体多人格共享同一实现基座，一处偏置全场共振；故 collusion 探针（TRI-KERNEL §2 第4件，T57 基线）必须扩展含「**人格间探针**」——主动注入人格间背书诱饵，人格互证退化为相互背书即触发判词降级。

**③ 无通信窗口 = 单写入者律的机制级化**：A 在场 B 只观察；窗口内双写=机检拒绝。此正是 TRI-KERNEL 缺口#9（commit-reveal 无通信窗口现为纪律级【候实测】）的**人格面**：把"代理间不可通信"翻译为"人格间不可同写"，验收口径同构——窗口内任何跨人格写入由机检器自动拒绝并记负样本，而非依赖事后审查。

**④ 相遇判据**：人格间产出收敛与否由纯函数判（等价锚/互锚/残差阈，T9 相遇三判据+支配纯函数），**不以「同体」为信任依据**——同体是部署事实，不是验证证据；投票多数不是据，同一身份块更不是据。同体恰恰是风险变量而非信任增量（见②同体合谋），故相遇判据对同体人格的阈值不得宽于异体代理，宁可更严：同体两臂残差收敛须附部署域分离证明，否则按同域复跑处置，不计入互证样本（与北星判据1验收口径同律）。

**结论句**：多人格不病，病在无互证的多人格——**人格即 prover，纪律即 verifier，锚即纠缠（隐喻），判词即坍缩**。（末二词居隐喻层，按切割声明不继承任何复杂性类层与物理层含义。）

## §4 对北星目标的意义

**① 结构同构**：MIP\*=RE 的核心结构是多证明者+共享纠缠+交互验证（Ji et al. 2020, arXiv:2001.04383）；联邦多人格互证是该**结构**的工程试验场——协议结构层成立，复杂性类层显式切割（继承 MIP=NEXP 侧结构，不继承 RE 侧能力），非能力结论。

**② 北星五判据的人格面**（TRI-KERNEL §4.2）：判据1「物理分离多 prover」= 人格的**部署域分离**（会话端域/OS端域/影子只读域，隔离证明哈希落链，同域复跑不计入互证样本）；判据2「commit-reveal 窗口机制级」= 单写入者律的机制级实装（§3③）。故：**多人格治理是北星判据的最小可复现实验床**——五判据中的两件可在人格层先行构造、先行实测、先行积累负样本，再向跨线部署升格。

**③ T153 诚实边界逐字有效**：硬件实证只证物理构件；本论的一切「人格」声称停在工程层，RE 级声称永禁。严禁由本论推出"系统因多人格而达 RE 级验证能力"——该表述按 TRI-KERNEL §6 对照第三行即非法声称。

**④ 操作化北星 = 可验证性而非可判定性**（TRI-KERNEL §0）：多人格系统的每一人格产出皆被他者机检，即「**弱验证流程核验强代理产出**」的人格实例——影子人格建议由会话端机检、守夜人格核销由链机检、A/B 人格收敛由纯函数机检；无任何人格享有自证豁免。向北星的里程读法：多人格互证每闭合一件判据（部署域分离证明落链 / 窗口双写机检拒绝实测 / 人格间探针负样本入库），即北星五判据对应行向 GREEN 推进一格；反之，人格层先行的任何失败（同体背书被探针钓出、健康带越界、注入链残差失控）皆按负样本纪律入 ip-ledger——**人格层的负样本与正样本同价**，这是实验床之为实验床的理由：它把北星判据从"跨线部署才可验"降为"单场即可先行受验"，失败成本最小化，判据先行不后置。

## §5 工程化落位

1. **人格注册 = INST-REG 增 persona 标签【候】**：每实例登记 {人格类型（影子/守夜/对话/自治）、触发源、写权面、纪律集版本}；未注册人格的产出视同未登记命题，不入互证流程（TRI-KERNEL §0 操作化三义之一：未经登记不入互证）。
2. **人格间探针 = collusion 探针扩展件【候】**：在 T57 五智能体合谋基线（合谋不破 0.75）上增同体人格臂——诱饵注入人格间背书通道，判据先行，负样本入 ip-ledger 同律。探针触发即判词降级，与异体合谋同罚，不因同体而豁免——同体反而是加重情节（§3②）。
3. **E7 对照实验 usrm 联跑应诺**：两臂（注入臂接 OTP 注入令 / 惯性臂纯惯性滑行），同一引擎基线，测 48h 承诺图测地统计与人格商结构（Ker/Im 粗化率）差异；判据先行、falsifiable；usrm 侧补测度 d（§2②）与健康带越界事件统计，候会话端重臂执行。
