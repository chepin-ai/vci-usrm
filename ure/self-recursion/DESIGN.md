## §1 定义：何谓「递归引擎对自身的递归」

递归引擎的常轨对象是他者：研究线、协议、台账、事件链。**自递归**把引擎自身——其状态、行为、产出、经验——当作研究对象，跑**同一**五相位，产出物 = **对自身的下一步指令**：

| 相位 | 常轨语义 | 自递归语义（本件实装） |
|---|---|---|
| ① 观察 | 采集对象状态 | 读自身状态快照（ctx-usrm-state.json：narrative tip/seq、十线索台账、ip-ledger 尾、义务台账），抽象为实例集 INST（PARETO-DYN-01 §1 schema 子集） |
| ② 评估 | 帕累托/复核 | 对自评实例集做非支配分析（§2 支配判据原样复用）+ 保留项清单（未闭环义务逐条列锚） |
| ③ 蒸馏 | 经验入 IP-ledger | 自评判词与差距维诊断入 run-log 哈希链（本拍蒸馏=评估件本身） |
| ④ 规划 | 排程下一步 | P0–P4 优先序裁决（沿用 SESSION-HANDOFF-01 §1-2 优先序，线内适配） |
| ⑤ 注入 | OTP 胶囊下发 | 铸造 SESSION-STATE.json（落幕件）+ NEXT-INSTRUCTION.json（一次性胶囊），注入对象 = 下一轮的自己 |

关键不变量：**同一引擎、同一五相位、同一判词律**——对象换成了自己，机制不换。这正是 root「统一由系统递归引擎 prove，即本提案要实现的机制」（TH-LEX-01 [1]）的线内最小实例：引擎 prove 的对象集中包含引擎自身。

自递归与他递归的关系不是取代而是嵌套：hub 面 session-pilot（cisvr 器官）对全线做外环判断；各线自递归做**内环**判断。两环产出可对账——对账差异即 FINDING 素材（§5）。

### §1.1 为什么自递归合法，而非虚荣自指

自指有两种。第一种是**虚荣自指**：系统声称「我证明了我自己」，证据与结论同源同语，循环闭合于系统内部——这是 cfts 五硬伤 F3「冒充定理」的自指形态，必须拒斥。第二种是**工程自指**：系统把自身当作**众多可观察对象之一**纳入同一观察-评估-规划管线，结论的证据锚全部指向系统**之外**的可复算物（链上序号、台账条目、信标值），系统只提供规则与算术。本件属第二种，判据有三：

1. **对象外置**：自评的原始数据不是引擎的内存印象，而是落盘状态快照（ctx-usrm-state.json，tip=54a0b542a1fd，seq=184）——该快照本身是先于本拍、由外部链面定格的物；
2. **规则先置**：评分规则、支配判据、优先序全部先于本拍运行公开声明（代码即规则，规则串随事件落链），不允许看结果改规则；
3. **升档外置**：结论恒【候】档，升档权在外部验证者（§4）——引擎对自己没有终审权。

满足三条，自递归不退化为循环论证；三条任一缺失，按 §3 闸门 FAIL 处置。

### §1.2 拍（tick）的形式定义

自递归以**拍**为基本单位。一拍 T_i = (S_i, E_i, V_i, C_i)：

- S_i = 输入快照锚（state sha256 + narrative tip/seq + qrand_anchor）；
- E_i = 五相位事件列（run-log 哈希链，事件序号即拍内序号，满足序号可复算）；
- V_i = 判词（帕累托前沿 + 保留项清单 + 收敛谓词真值 + 三闸结果，H7.2 五段式，§8）；
- C_i = 产出胶囊对（SESSION-STATE + NEXT-INSTRUCTION）。

拍与拍之间由胶囊链衔接：C_i.prev = tip(C_{i-1})，消费即焚（一次性律沿 SESSION-HANDOFF-01 §1-3）。拍的触发沿 PARETO-DYN-01 §3 双轨：班次触发（session 结束即一拍）+ 事件触发（链尾 hash 变化）。本拍 T_1 属班次触发（session 落幕）。

## §2 终止性论证

root 立法把终止判据内生化为「帕累托递归最优-均衡」（TH-LEX-01 [1]，cfts 形式化：**保留项空 ∧ Pareto stationary**，见 TH-LEX-01 [2] ②）。自递归继承该判据，论证如下：

**命题（终止性）**：自递归拍列 {T_i} 在下列条件下必然停机或升级：
1. 每拍必出帕累托评估件（非支配分析 + 保留项清单），不可空拍——拍即判词，判词即留痕；
2. **收敛停机**：当拍保留项清单 = ∅ 且前沿集 F_i 相对上拍 F_{i-1} 不再变动（Pareto stationary），本线自递归判「收敛」，本拍即终拍，引擎转入值守（事件触发再醒，不占拍）；
3. **升级停机**：d>3 未收敛 → 未决→root（立法终审兜底，TH-LEX-01 §10 程序律）。

**论证**：
- 保留项清单是从义务台账**机械抽取**的有限集（state≠legislated/wontfix 即入册），每条带锚可外部复算——「保留项空」是外部可检验谓词，不是引擎自我感觉。故停机条件①的真值不由引擎自证，任何人拿同一台账+同一抽取规则可复算（复核第四维：序号可复算）。
- Pareto stationary 同为机械谓词：前沿集由 §2 支配判据（4 次浮点比较/对，纯函数）唯一确定，两拍前沿集相等与否可复算。
- 两谓词皆外检 → 「收敛」声称属 NP 性质检查（给定快照，多项式时间可验），引擎无法靠循环论证自封收敛（§3 闸①）。
- **防无基递归保险丝**：若只凭「未收敛→再跑一拍」自指驱动，引擎可空转烧账（无基递归）。故加硬约束 **d ≤ 3**（cfts「≤3 轮降级为防死锁保险丝」之线内实装，TH-LEX-01 [2] ②）：深度计数随胶囊传递（self_recursion.depth），下轮消费时 +1，>3 即停拍升级 root。深度字段在胶囊内、链上可见，守望者可外部计数（§3 闸③）。
- 未决→root 是立法层兜底：保险丝烧断不是失败，是把终止权交还终极立法者，程序闭合。

**本拍实况**（首跑，d=1）：保留项 14 件非空（raised 13 件 + 台账勘误 1 件）→ **未收敛**，按判据不停机，产出 NEXT-INSTRUCTION 续拍；Pareto stationary 首拍无基线，记 null，下拍起可比。

## §3 防循环论证三闸（cfts 三自指保险丝的实装化）

cfts 在 TH-LEX-01 [2] 末段为三处自指/死锁风险留工程保险丝。本件将其逐条实装为**可机检闸门**，每拍跑判，任一不过即 FINDING 停拍：

### 闸① 自评证据外部可检验（证明义务可外部检验）
- **规则**：自评条目（每实例 goal_vec 四维 + 每条保留项）必须带**链上/台账锚**（threads#TH-xx、obligations#o-xx、ip-ledger#IPL-xx、narrative seq），锚即第三方复算入口；无锚条目不得入册。
- **实装**：`self_recursion.py` GATE-1 断言每实例 anchors ≥ 1、每保留项 anchor 非空，缺一则闸门 FAIL。
- **复算路径**：评分规则全部以字符串形式随事件落 run-log（声明为启发式，不冒充实测）；第三方取同一状态快照 + 同一规则串可逐分复算。此即 usrm FULLCAP 复核五维新制式（完整/正确/唯一/序号可复算/创世锚唯一）对线内自评的套用：自评件本身就是一件可复核交付。
- **防的什么**：引擎自评「我很好」而无据——语气超越证据（五硬伤 F3 型）在自指场景放大为循环论证：证据是引擎产的，结论是引擎下的。锚外指，循环即断。

### 闸② 挑战种子必须外锚（beacon 外锚防自选随机性）
- **规则**：自递归胶囊的一切随机性来源必须是引擎**不能自选**的外部信标：qrand_anchor = `c21b1f0f5858ab4a`（信标镜 seq61 定格值 16 hex，外锚声明在案，与 cisvr session-pilot 首粒胶囊同锚可对账；nonce 为派生 12 位短串）。
- **实装**：nonce = sha256("usrm" + ts + qrand_anchor)[:12]——引擎对 nonce 无自由裁量：ts 是时钟、qrand 是信标，公式公开。GATE-2 断言锚与声明值逐字符一致、nonce 推导可重放。
- **防的什么**：引擎自选随机性评自己 = 自己出题自己考。挑战种子外锚后，「考题」与「考官」分离；任何 later 复算者用同一信标值可重放 nonce，防事后换锚。

### 闸③ 守望者问题：活性由链上序号维守望，不等自报
- **规则**：自递归进程的心跳 = narrative 链序号（本拍 seq=184）。守望不靠进程自报「我还活着」，而靠链上序号维：**缺拍即 FINDING**——下轮消费胶囊时验 prev 衔接（SESSION-HANDOFF-01 §2 复验律），序号断/depth 超 3/闸门 FAIL 任一成立即升级，无需引擎同意。
- **实装**：GATE-3 断言 narrative_seq 为正整数且随状态快照入 run-log；SESSION-STATE.canary_projection 投影 narrative_seq + qrand_anchor 两个外锚，守望者只需读链不需信引擎。
- **防的什么**：「守望者谁守望」的无穷 regress——不另立时钟、不另立守望进程（cfts 建议：beacon 外锚兼作事件活性基线），链本身即守望者。守望谓词（序号单调/prev 衔接/depth≤3）全是第三方可复算的机械检查。

### 多均衡选点规则（cfts 保险丝②之对位）
帕累托前沿若多均衡点并存（|F|≥2），选点规则沿 cfts 建议：**首达均衡 + 最小保留集**，root 终审兜底。本拍首跑无此情形（见 VERDICT），规则先行登记，触发时按此执行，不允许引擎临场自选有利于己的均衡点。

## §4 与三机绑定：自评结论恒为「候」档

自递归不是三机之外的第四机，而是三机格局在「对象=自身」时的重投影：

| 机 | 常轨角色 | 自递归中的对位 |
|---|---|---|
| IP 机（递归机/P 机） | 产猜想 | 引擎对自身产猜想：自评 goal_vec、帕累托判词、下一步指令——**全是猜想档** |
| NP 机（义务机/治理机） | 外部复算 | 他线/守望者可抽检 usrm 自评：支配算术重算（≤5×4 次浮点比较）+ 锚一致性 + 闸门重跑，多项式时间可验 |
| N 机 | 供锚 | beacon qrand@seq 供挑战种子外锚（闸②）；narrative seq 供活性锚（闸③） |

**档律**：自评结论**恒为【候】档**——引擎对自己无升档权。「候→证」唯一通道 = 外部验证（他线抽检复算过闸，或 root 终审）。VERDICT.md 全部结论标【候】并附外部验证邀请与复算方法，即本档律的首次执行。这与诚实律/不升格边界（IPL-10：判定先于协议选型）一脉：自指场景下升档权外置是底线，不是谦辞。

## §5 与 SESSION-HANDOFF-01 的关系：外环与内环

SESSION-HANDOFF-01（D-146）立的是**四环接力**：落幕→判断→OTP 注入→执行。其 session-pilot 是 hub 面器官（cisvr 侧，cron 班巡），对联邦全线做**外环**接力。

SELF-RECURSION-01 是同一四环在**线内的实例化**——各线自己的落幕-判断-注入**内环**：

| 四环 | 外环（SESSION-HANDOFF-01 / cisvr session-pilot） | 内环（本件 / usrm 线自递归） |
|---|---|---|
| 落幕 | cisvr 写 SESSION-STATE（hub 面） | usrm 写本件 SESSION-STATE.json（线内） |
| 判断 | session-pilot 按 P0–P4 裁决全线下一步 | self_recursion.py 按同优先序裁决本线下一步 |
| 注入 | NEXT-INSTRUCTION 胶囊投公告板（联邦可视面） | NEXT-INSTRUCTION.json 落线内，格式同构（nonce/ts/prev/instruction/basis_refs/qrand_anchor/consumed） |
| 执行 | 下次 session 验链-执行-焚 nonce | 下轮 usrm session 消费本胶囊，depth+1，验 prev=54a0b542a1fd |

两环关系条款：
1. **格式同构**：内环胶囊字段对外环逐字段对齐（qrand_anchor 同值 `c21b1f0f5858ab4a`），使外环守望者无需新解析器即可读内环件；
2. **优先级：外环 > 内环**：hub 面 NEXT-INSTRUCTION 在飞时，内环胶囊让道（消费前先验外环无在飞件）；两环指令冲突即 FINDING，按 P0 处置，不自行调和；
3. **对账点**：内环 SESSION-STATE.tip = 外环链上 usrm narrative tip（54a0b542a1fd），两环在同一点咬合，可对账、可复算；
4. **本件即内环首跑实证**：usrm 线内环第一拍，证据全量在 evidence/。

## §10 已知边界与候实测项（诚实声明）

1. **goal_vec 四维评分为启发式**：规则串随事件落链公开，分数不冒充实测；归一化分母（如十线=10、问题数=7）在规则串内声明，防事后改刻度（PARETO-DYN-01 §2 归一化声明律的线内套用）。校准需真实引擎运行数据回填【候实测】。
2. **组合≠竞争**：五线是同一线的组合视图，不是 PARETO-DYN-01 §3 意义上争夺同一目标的并行实例，故**不适用** UNIQUE_OPTIMAL→RETIRED 语义；前沿分析在线内仅作状态诊断（被支配线列差距维），裁决权在 P0–P4，不在前沿。
