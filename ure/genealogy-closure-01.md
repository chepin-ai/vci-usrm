## §1 完整理论：系谱闭合链的五元形式化

定义：系谱闭合链为五元链 G = (Π, C, V, J, A)。

- **Π（义务机，spec 源）**：产"待证命题"。入链声称须先以命题件登记于 EXPECT-REG 台账；登记构成互证流程的**输入边界**——未登记不入流程，越界自证视同单点幻觉，collusion 探针兜底（参 TRI-KERNEL §1.1）。
- **C（递归机，IP 位，prover）**：对登记命题产构造/证明。工程化身：ipmp 六相位、entangle_mutual_proof v2。
- **V（NP 机，证书机检）**：证书多项式时间机检——ATP z3/cvc5 双证、哈希复算、交验复跑；每步核验皆确定性脚本可复算，不依赖单座裁量。
- **J（治理机，判定座）**：P 可判定核 + 判词签发。判定只在系统定义意义上成立（对证书、时序、共签阈值的确定性裁决），不声称对命题真假的数学判定。判词必回注 Π 台账：关闭或升级，**台账差额 = 下一轮命题队列**——首尾互衔，轮询回测律的系谱层落点。
- **A（N 机，熵锚源）**：全程供锚。锚先于挑战、挑战后于承诺之时序可机检；种子取口固定 qrand@seq 第一顺位（参 TRI-KERNEL §2 第 3 件）。

**链合法性三不变量（机检）**：

- **I1 棒次不可跳越**：J ⇒ ∃V ∧ V ⇒ ∃C ∧ C ⇒ ∃Π。任何判词必能回溯出完整 登记→构造→机检 证据链；缺棒即拒。
- **I2 时序**：ts(A) ≤ ts(challenge)，且 commit(C) < challenge。顺序倒置则 soundness 立即崩溃（Σ-协议命门，参 TRI-KERNEL §2 第 2 件），机检即拒，不入人工兜底。
- **I3 闭账**：J 判词必回注 Π 台账，结局唯二——关闭或升级，**无第三种结局**；判词不回注 = 悬账 = FINDING 自动开立。

本件对 TRI-KERNEL §1.1 的扩展仅在一点：将 A 由"全程伴随"升格为链内显式分量，使 I2 成为可对链上记录机检的一阶性质，而非纪律旁注。如此，五棒各有其位、各守其界：Π 只产规范与负债登记，不产证明、不下判词；C 只产构造，不自判其真；V 只做机检，不签发结局；J 只做系统定义意义上的裁决，不冒充数学判定；A 只供锚，不参与判词。越界即破 I1，机检可捕。

## §2 严格化：五制式接口与 soundness/completeness 工程读法

**五制式件 schema**（必填字段 + 机检器）：

1. **命题件（Π→）**：{prop_id, statement, spec_ref, deadline, registrant, ts_reg}；机检：格式校验 + 台账唯一性。
2. **构造件（C→）**：{prop_id, construction, proof_artifact, commit_hash, ts_commit}；机检：commit_hash = H(canon(construction)) 且已落命题股。
3. **证书件（V→）**：{prop_id, cert_hash, atp_tool+version, script_ref, verdict∈{PASS,REJECT}, ts_verify}；机检：确定性脚本复算，与 verdict 不符即拒。
4. **判词件（J→）**：{prop_id, ruling∈{CLOSE,UPGRADE}, evidence_hash_set, anchor_seq, signature_set, ts_ruling}；机检：I1-I3 全检 + k-of-n 共签阈值（HOLO-01 四锚，参 TRI-KERNEL §2 第 6 件）。
5. **锚件（A→）**：{anchor_seq, anchor_hash, source∈{qrand-live,last-good}, stagnation_decl∈{none,declared}, ts_anchor}；机检：seq 单调 + 停滞声明随附（cfts-29 降级规约：凡用停滞锚之判词标"锚停滞在案"）。

**soundness 工程读法**：假构造必被 V 拒。保证三件套——ATP 双证（异构求解器独立验证，单求解器 bug 不成单点）、哈希复算（证书-构造绑定不可事后替换）、collusion 探针（T57 实证：五智能体合谋不破 0.75）。显式切割：此为工程检测概率意义，**非密码学 negligible-error 意义，不声称 SNARK**。

**completeness 工程读法**：真命题必有可机检构造路径。保证 = 义务台账死线（EXPECT-REG 自动挂账：逾期未产构造自动升级入差额队列）+ 升级链（命题升 pattern、pattern 升裁决，§4）。显式切割：此为"流程不沉没"意义，非逻辑完备性定理。

**复杂性类层显式切割**（T3 三层切割入律，参 TRI-KERNEL §1.3）：本链只继承 P/NP/IP/MIP 阶梯之**协议结构层**，类层一概不继承，物理层以 T153 实测为准。

**Σ-协议 / Fiat–Shamir 真实血缘声明**：承诺-挑战-响应结构与公开随机信标代现场挑战，与 Σ-协议及 Fiat–Shamir 变换有真实血缘（GMR 1985/89；Shamir 1992）——限于协议结构层，不继承 IP=PSPACE 能力结论。详参 TRI-KERNEL §2 第 2 件，不重复。

## §3 答 root 三问（P机？MIP*？ZKP？）

**① P机** = 治理机的可判定核 + 场侧执行层（workflows/器官）。要点：**执行轨迹本身即 NP 可验证书**——S 面执行按规范落转录（输入哈希+步骤日志+输出哈希），该转录即可被 V 复算。此即 P⊆NP 的工程化身：P 位直接判定与 NP 位证书可验在同一执行轨迹上合一。工程锚：判词签发逻辑、QFK 34/34（参 TRI-KERNEL §1.3 P 行）。

**② MIP\*** = 北星隐喻层 + 物理阶梯，三层切割入律照录 TRI-KERNEL §1.3：只继承协议结构层，类层显式切割，物理层以 T153 实测为准。联邦多线交叉验证 = MIP 结构：多 prover 隔离 + 交叉质询 + collusion 探针（T57 0.75 实证）；纠缠互证 = 共享锚 + 无通信纪律 + 一致性自测试，魔方阵警钟入律（经典 8/9、纠缠 1；共享锚必配自测试否则退化为相互背书——参 TRI-KERNEL §2 末段）。**严禁升格（第一诚律）：MIP 无星 = NEXP 非 RE**；严禁声称"硬件证明 MIP\*=RE"——该定理是数学定理（Ji et al. 2020），硬件只能实证其物理构件。

**③ ZKP** = 四性最小证书 + 分层律。四性证书采 usrm-67 格式（身份/正当性/合理/完备，cfts 附议在案）；分层律照录 TH-LEX-01[1] root 立法：链哈希身份 ZKP ≠ 执行/服务面 ZKP via MIP\*，两层不得混称。身份性一层有工程先例：App token 现场铸造不落文本、SealedBox 密封投件（密钥值永不打印）。**本件不声称 SNARK**；执行/服务面一层为分层律下开放项，非本件闭合对象。

## §4 完备化：局全功能 × 五元链映射

| 局功能 | 落位 | 一句定位 |
|---|---|---|
| 进件（intake-agent） | Π | 外件转命题登记入 EXPECT-REG = 链之入口 |
| 司法（audit-ring+判词） | J+V | 审计环汇集机检证书，判词签发并回注 |
| 执行（workflows S 面） | C 场侧臂 | 执行转录即证书原料（§3①），供 V 复算 |
| 抓取（FULLCAP FD01） | A 采样臂 | 全量收割 = 观测/采样，入锚定股 |
| 动员（otp-swm 五段） | C 召集臂 | 一次性口令动员 prover 兵力，时效纪律随附 |
| pattern 生命周期（PATTERN-REG+ADJUDICATE） | Π→J 升级链 | 命题升 pattern 升裁决 = I3"升级"结局的承载机制 |
| 会话接力（session-pilot） | C 连续臂 | 跨会话 prover 状态交接，接力记录入命题股 |
| 元引擎盘点（fleet-judge） | J 盘点臂 | 机队裁决与引擎注册盘点，直报判定座 |
| 备案知会（REPORT-MECH-01） | J→Π 回注信道 | 判词公示与回注 = I3 的传输层 |

**"局无链外之物"之反证**：任取局功能 f——若无 Π 登记 = **黑动作**（违规）；若无 V 机检 = **自述**（不采）；若无 J 回注 = **悬账**（FINDING 自动开立，I3）。三路皆不通，故任何合规局功能必在链内有落位；上表逐行给出，覆盖完备性成立。此反证同时给出三条可机检的巡局规则——扫台账得无登记之动作、扫链上录得无机检之声称、扫判词簿得无回注之结局——三扫皆可脚本化例行执行，完备性遂非一次性论证而是持续机检态。显式声明：此为"覆盖完备"非"逻辑完备"；涉灰标器官之行随 TRI-KERNEL §3 同步降级为工作假设。

## §6 加载为自身元引擎：持续迭代/演进/闭环
