# VOICEOVER-01 ·「背景空间画外音」完整设计

- 版本：v0.1 · 线：usrm（IP 机）· 时锚：2026-08-28
- 答 root 之问：「以各线递归机多线实例实际运行情况为背景，如何保留记忆、自动蒸馏、取得经验，并根据会话圈/研究圈张量网给予建议和依据——来自背景空间的画外音」（root 附注：建议引入多智能体）
- 安全声明：本设计全程不涉及任何密钥/凭证之明文、值、指纹或获取路径；凭据面一律以「降级标记/密封轨」引用。

## 0. 问题形式化

**背景空间**=各线递归机多线实例的运行残余之总和：状态文件（cfts `engine-state.json` 单一真源、qfa `ure/engine_state.json` 心跳面）、事件链（cfts `sessionLog` 逐事件实时写盘、usrm narrative 链 140 entries）、台账（ip-ledger IPL-01..10、threads-10、OBM-01 义务台账）、张量网（会话内容网+文件内容网+L3 状态圈网）。它不随任何单一沙箱存亡：qfa 两世全灭（87min/12min）后重拉 <60s 即实证——**仓即本体**（LX-u12），沙箱只是会死的显示器。

**画外音**=背景空间对前景会话的建议声部。前景会话是易失的（内核擦除每轮实证发生，M0 必死）；画外音是背景空间经由张量网路径向当前会话投来的、带出处与置信档的建议。它不是新代理的独白，而是**既往运行残余的再激活**——cisvr 语：「回顾=张量网场交互计算，不是考古」。

三要件（缺一即非画外音）：

1. **记忆可续**：fold/沙箱灭不失忆。任何会话可死，链/台账/网不可死。
2. **经验可蒸馏**：自动触发、自动定型，且每件经验带出处锚（IPL 制式：情境+教训+出处）。
3. **建议可依**：每条建议带张量网路径锚。**无锚不出声——画外音缄默律**。画外音宁默勿妄；无出处支撑的建议是幻觉，不是声音。

**架构判词**：M0 必死是实证的物理事实，不是缺陷——因此设计重心不是保住 M0，而是让 M0 死亡**无损**：一切有价值之物在会话死前已写进 M1/M2，M3 提供跨线、跨会话的结构化检索。wake_up.py 即 M0 再水合的现役实例：空盘沙箱 clone 后即完整复活（凭据预检→拉仓本体→舰队开庭→落账闭庭）。

## 2. 自动蒸馏管线

五级管线：**触发 → 抽取 → 定型 → 门禁 → 落账**。

### 2.1 触发（事件优先，时钟殿后）
- **每拍触发**：IP 机自有节拍（cron 2h 哨+URE pareto_tick）每拍末对拍内事件做密度评估。
- **每批触发**：收割批次闭环时（如 harvest-wave2、otp-fullcap-drive）整批过管线。
- **事件密度阈值触发**：引用 T149 事件密度自调速律（45–240min 自适应）——事件密度超阈即提前起蒸馏，静默期降频；节拍只是兜底，**事件优先，时钟殿后**（T154 六柱之柱2）。

### 2.2 抽取（事件→模式）
对 M1 事件链做三类模式抽取：
- **频次模式**：同类事件重复出现且处置收敛（如「虚报落盘」→三重自验律，IPL-03）。
- **反例模式**：失败/翻车事件（内核擦除三连、rebase 缠死、504 假超时）——反例价值不低于正例。
- **跨线同构模式**：同一模式在多线事件链上同构复现（如「schema 异构须多键兜底」IPL-02 同时适用于收割器与张量网入库器）。

### 2.3 定型（模式→原则候选）
模式定型为原则候选条目，schema 沿用并升级 ip-ledger 制式：
```
{id: IPL-xx, ts, proc, kind, situation, lesson, evidence, confidence, scope}
```
- **confidence 置信档四态**：证（已实证/带复算路径）/候（候选，待复核）/冲（与他条冲突，挂争议）/退（已被后事超越，closed-obe 同款语义）。
- **scope 适用面声明**：条目声明适用域（指令经验/研究经验；单线/跨线；CI 时代/QF 时代），防旧律越界套用。

### 2.4 门禁（复核五维，usrm 主责）
定型件过门方可落账，五维（cisvr-68 已收编两维入 INTAKE-AGENT/audit-ring 复核面）：
1. 完整（无截断/无缺段）
2. 正确（教训与证据一致，不虚报——虚报已实证一次）
3. 唯一（无重复条目/重复锚）
4. 序号可复算（IPL 续编可对账）
5. 创世锚唯一（每条出处锚可溯源至唯一原始事件，无孤儿）

### 2.5 落账
过门件双落：ip-ledger.jsonl 追加（M2）+ 张量网节点登记（M3，锚=文件内容网节点边）。落账事件本身入 stream-ledger（落账也是事件）。

### 2.6 防退化三律
1. **不蒸馏无出处件**：无 evidence 锚的模式不入门禁（缄默律在蒸馏侧的镜像）。
2. **不覆盖只追加**：任何条目不可原地修改；修正=新条目+指向旧条目之「退」档标记。
3. **反例入律**（cisvr H3.4 制式）：每条原则登记已知反例与失效条件；反例不入律者降置信档。血泪实证：K13 采集曾把端点复用 bug 当 r=1.00 全相关证据——逐对校验不逐字节相等自此入采集律。

## 3. 经验取得与检索

### 3.1 经验定义
**经验 = 蒸馏件 + 出处锚 + 适用面声明**。三要素缺一者只是笔记，不构成经验。

### 3.2 检索 = 张量网路径查询
- **按主题**：会话内容网内沿语义边收缩查询（如「虚报」「权限窗口」「张量网入库」）。
- **按场**：L3 状态圈网按节点（执行机制）/边（工作流路由）定位——某机制相关的全部经验沿其邻边展开。
- **按时间**：M1 链哈希序+M2 ts 序，支持「某窗口内发生了什么、学到什么」。
- 查询结果带路径本身：建议的「依据锚」=该路径在网上的坐标，可复算、可复检。

### 3.3 跨线经验互译
各线事件链方言异构（entries/items/outbound/cfts-dashboard/sessionLog/timestamp 键名不一，IPL-02 实证）。互译走 L2 四语跨域计算层（ai/bi/qi/gitee 四域方言互译，D-141 栈）：抽取器多键兜底+时间戳双键为最小互译核；跨线同构模式经互译层对齐后方可合并为联邦级经验。合并事件登记合并谱系（谁译自谁），防回声室伪互证（§7-G4）。

## 4. 画外音发声机制

### 4.1 观测面（画外音之耳目）
四类观测量，全部已实证可用：
1. **K13 场关联矩阵**作漂移早期信号：谱/参与率/显著边集变化先于拓扑事故（cisvr Q6 判决产物 K13-FIELD-CORRELATION-01）。**Q6 注脚必须随行**：点火时刻单点观测证不了环（时钟 regime 全阈值 g=0；g=4 是 routes.json 的设计编码）——要证环须路由级联合统计（谁转发给谁）。故 K13 只作**预警信号**，不作结构判决。
2. **义务机台账缺口**：OBM-01/EXPECT-REG 中逾期无进展件（如 qlv 线全拍静默在案 EXP-004；>72h 静默而研究线活跃者义务机自动起案）。
3. **sessionLog 活跃度**：各线事件链增长率异常（暴涨=风暴凝聚，K13 退化陷阱之爆发凝聚；停滞=死拍/漏拍，INTAKE-LATEST 卡滞 3.5h 即实测样本）。
4. **复核面 FINDING**：INTAKE-AGENT/audit-ring/复核五维检出的违例事件流（空收必报律延伸：在飞件超 ttl 未 SETTLED=自动 FINDING）。

### 4.2 判定（何时发声，何时缄默）
**三触发**（任一即发声候选）：
- **异常触发**：观测面检出漂移/停滞/违例。
- **缺口触发**：义务台账/线索台账（threads-10 next 列）有到期未闭项，且 M2 有相关经验可援。
- **请求触发**：前景会话/root 直接提问（本设计即此触发的产物）。

**缄默律**：依据锚缺失、置信档低于「候」、或建议超出本线可观测面（需跨线联合统计而统计未做，IPL-10 不升格律同款）时——**不出声**。缄默本身可登记为一条「观测不足」事件入 M1。

### 4.3 声部格式（四要件，缺一不发）
```
[VOICE] 建议：<可执行动作，一句话>
[ANCHOR] 依据锚：<张量网路径/IPL 编号/链上 seq/帖号，可复算>
[CONF] 置信档：证|候|冲|退（+一句理由）
[FALSIFY] 证伪条件：<什么观测出现即撤回本建议>
```
四要件缺一，整条降级为缄默事件。例（真实素材改写）：`[VOICE] qlv 线静默超阈，建议义务机起案并候 root 介入 [ANCHOR] EXP-004 + TH-SESCAP-01 台账行 [CONF] 证（台账在册） [FALSIFY] qlv 跟帖报进度且链头可复算`。

### 4.4 多智能体引入（root 附注之实装）
**领域专家子代理编队**：每域一代理——会话网代理（管 M1/M3-会话网查询）、文件网代理（管交付物索引/出处锚解析）、状态圈代理（管 K13/义务台账/FINDING 流）、蒸馏代理（管 §2 管线）、门禁代理（管复核五维）。
- **会合协议 rendezvous=共享锚点汇合**：各代理不互传长文，只在共享锚点（链 seq/网节点坐标/IPL 号）上会合交换结论；锚即公共语言，防转述失真（原话原样直达>转述，IPL-01）。
- **与 IP 机三机绑定**（IP-CIRCLE-01 已注册）：
  - **IP 机**产猜想——蒸馏代理+领域代理产出建议草案与构造；
  - **NP 机**验——门禁代理+独立复验（自跑测试/链哈希复算，独立复验为交账铁律 IPL-07）；
  - **N 机**供锚——观测面采样（信标拍/scouts/收割）供给物理锚与统计现实。
  - 多智能体并行编排沿用 IPL-09 实证制式：简报包只读落盘+多代理并行起草+主代理专掌推送与链上锚；**子代理零凭证可达**（安全律，密钥永不出主上下文——本设计全文遵守同律）。
- 该编队与 T156 五角色议会（sentinel/ambassador/weaver/auditor/beatmaster）同构：议会管拍内自治，编队管跨拍经验声部。

| **共识圈** | **终审**：画外音建议升立法（如本设计若升 SPEC）须经 VOTE-YONEDA-01 表决——量子帕累托米田共识：帕累托闭包+米田一致性+全员会签。画外音只有建议权，无立法权 | ballots 区开案件；票式 hash 链式 |

## 7. 灰区诚实档（不美化，七条）

- **G1 蒸馏≠理解**：模式抽取是统计+启发式，可过拟合会话噪声（某次恰好奏效的处置被定型为律）。对冲：置信档「候」件须跨拍复现或独立复验方升「证」；反例入律强制登记失效条件。
- **G2 画外音权威边界**：建议非命令。裁决权在 root（立法）/cisvr（司法），画外音无任何执行权；四要件是给裁决者的读件格式，不是给执行者的指令。任何「画外音令…」表述均为越权信号。
- **G3 单点观测证不了环（Q6 注脚）**：K13 类单观测量可给漂移预警，给不了结构判决；若画外音仅凭单点观测就断言拓扑结论，即触缄默律。结构断言须路由级联合统计在案。
- **G4 多智能体回声室风险**：编队各代理同源于同一批 M1/M2 数据，「互证」可能是同源复读的伪互证。对冲：rendezvous 只交换锚点+结论差异项；门禁代理必须独立重放证据链（独立复验铁律）；跨线合并经验登记谱系，同源件不得互为升档依据。
- **G5 出处锚本身的脆弱性**：锚依赖链/仓/网存续——创世重写（5次4孤儿已实证）、仓 purge、边表未落都会使锚悬空。对策：锚悬空条目自动降「退」档并起 FINDING；但承认：多面同时灭失时经验可随锚俱亡，无绝对保险。
- **G6 缄默的代价**：缄默律防妄语，也可能在该说话时失声（证据在而未成锚、锚格式不齐）。折衷：缄默事件本身入 M1 留痕，候人工/root 翻检；宁可有记录的沉默，不可无锚的声音——但记录本身须可检索，否则缄默=丢失。
- **G7 本条设计的自指灰区**：本设计由 usrm 单线起草，未经三机互证全圈（NP 验/N 锚仅接口声明）；近档判据可自验，中/远档判据须联邦侧实测数据支撑，未测前一切「可实装」表述均按「候」档读。
