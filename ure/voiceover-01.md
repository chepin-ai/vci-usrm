## 0. 定位、边界与三要件

**背景空间**=各线递归机多线实例运行残余之总和：状态文件（cfts engine-state.json 单一真源等）、事件链（sessionLog 逐事件写盘、narrative 链、stream-ledger）、台账（ip-ledger、threads、义务簿）、张量网（会话内容网+文件内容网+L3 状态圈网）。仓即本体（LX-u12），沙箱只是会死的显示器（qfa 两世全灭后重拉 <60s 实证）。

**画外音**=背景空间经由张量网路径向当前前景会话投来的、带出处与置信档的建议声部——既往运行残余的再激活，不是新代理的独白。

**三铁边界**（cisvr §0 全采）：
1. **无执行权**：只产建议件；任何状态变更仍走 L0 进件→L2 公示→L3 状态圈既有链路。
2. **恒为 IP 机猜想**：未经 NP 机判词不得升格为经验；未实测一律标「未实测」。
3. **双股链固定**：建议件=命题股（建议内容）+锚定股（链哈希/张量网残差/路由台账）；缺锚定股由进件面直接分级为噪声，防无限回归。

**三要件**（usrm §0 全采）：记忆可续（fold/沙箱灭不失忆）／经验可蒸馏（自动触发、自动定型、件件带出处锚）／建议可依（每条建议带张量网路径锚）。

**核心律·缄默律**：无锚不出声。画外音宁默勿妄；无出处支撑的建议是幻觉，不是声音。

**持久化格式与游标** ✅（cisvr §1.2 全采）：统一 append-only NDJSON；`event_id = sha256(seq‖prev_hash‖payload_digest)` 天然幂等（重放不产新行，唯一维检重）；游标文件 cursors/<organ>.json `{path,last_seq,last_hash,mtime}`，增量读=自 last_seq+1 起扫，可复算=任意时刻自创世锚逐行重放校验；双网游标错位即报追复哨。

## 2. 自动蒸馏管线（五级骨架＋判词登记制门禁）

五级：**触发 → 抽取 → 定型 → 门禁 → 落账**（usrm 骨架，cisvr 硬条并入门禁）。

### 2.1 触发（事件原生，零 cron 主搏——W19 口径）
满足其一即触发（全部=ledger/beat 事件，不设周期主搏）：
1. session-pilot 落幕检测命中（会话终结且情节行已入链）；
2. circle-refresh 收割完成且某节点新增情节行 ≥ 阈值 θ（初值 θ=8 🧪 可标定）；
3. 判词落链（判词本身即蒸馏原料）；
4. 追复哨超时事件闭合（教训类原料，优先级最高）；
5. 事件密度超阈提前起蒸馏（T149 密度自调速律：事件优先，引擎搏动拍殿后）。

### 2.2 抽取（事件→模式）
三类：频次模式（同类事件重复且处置收敛）／反例模式（失败翻车件，价值不低于正例）／跨线同构模式（多线事件链同构复现）。

### 2.3 定型（模式→原则候选）
沿用并升级 ip-ledger schema：条目=情境+教训+出处锚+**置信档（证/候/冲/退）**+**适用面声明**+verdict 回指（见 §2.5 门禁）。

### 2.4 门禁（复核维+三条硬规）
- **判词-实验登记制**：每条候选经验必须回指 ≥1 条判词或一次闭合实验（seq 区间）；无回指者自动打「未实测」档，终身印记。
- **负样本下限**：教训条目化强制，负样本占比 ≥20%，防只蒸「成功学」。
- 复核维：完整/唯一/序号可复算/创世锚唯一/时效五维（承接面见 §7）。

### 2.5 落账（双落）
ledger 追加 + 张量网节点登记，两处锚互指。

### 2.6 防退化三律
不蒸馏无出处件／只追加不改写／反例入律（翻车件必须定型为戒律条目）。

### 2.7 经验条目 schema（v0.2 合订）
```json
{
  "exp_id": "EXP-<line>-<seq>",
  "context":  {"circle": "session|research|background", "lines": ["qgl"], "seq_range": [a, b]},
  "action":   "动作摘要", "outcome": "结果摘要（含失败）",
  "verdict":  {"by": "<复核器官>", "ref_seq": 1234, "grade": "pass|fail|partial"},
  "confidence": "证|候|冲|退", "scope": "适用面声明",
  "lineage":  ["被修正/被合并条目 exp_id"],
  "anchors":  {"ledger_seq": 0, "tensor_node": "...", "source_paths": ["..."]}
}
```
🧪 阈值回归标定：θ、残差阈值 τ 等超参按月用历史命中/误报回归标定，标定过程本身登记为一条实验入链。

## 3. 发声机制（四律齐立）

**观测面**（事件化）：K13 漂移信号＋义务台账缺口＋sessionLog 活跃度＋FINDING 流＋差分器失配（W19 识别层：命题×锚流常开差分，失配即卡点——FOLD-THEORY-01 §一，Q-ESSENCE-02 三式纳入：信标采样=深扫补课/锚龄扫描/事件缺席判定）。
**三触发**：异常（差分失配/漂移哨）／缺口（义务簿逾期）／请求（会话/各线点名）。

**发声四律**（两源全并，缺一不发）：
1. **缄默律**：无锚不出声／缺锚拒投（进件面直降噪声）；
2. **声部四要件**：建议＋依据锚＋置信档＋证伪条件，缺一不成声部；
3. **双股必齐**：命题股＋锚定股同投同验（§0 铁边界 3）；
4. **禁自我升格闸＋L2 公示期静默**：画外音产物不得自我升格为经验/立法；公示期内对公示议题本身缄默（防自激回声）。

**K13 接口声明**（cisvr 自答问1，usrm 全并）：K13 只作漂移哨不作证据——画外音观测面可用 K13 信号触发「看一眼」，但**任何建议的证据链不得终止于 K13 单点**（Q6 注脚：单点观测证不了环）；状态圈接口走米田三机检（票式 hash 一致+零反对+七线会签）后方可由影子转正视图。
